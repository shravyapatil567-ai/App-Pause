APP PAUSE — MOBILE DIGITAL PROTOTYPE
1. Extract this ZIP.
2. Open the extracted folder in VS Code using File > Open Folder.
3. Ensure Live Server is enabled.
4. Right-click index.html > Open with Live Server, or click Go Live.
5. The responsive screen is designed for mobile width. You can also resize your browser.

Use the arrows to select Instagram, YouTube or TikTok. Choose a usage limit (including the new 5-minute and 15-minute options),
then start. For limits longer than 15 minutes, reminders can appear at 15 and 5 minutes remaining if checked. For a 15-minute limit, only the 5-minute reminder can appear; for a 5-minute limit, these longer warning intervals are skipped. When
the limit expires, the 90-minute lock starts. Emergency access lasts up to
30 minutes, then returns to the lock.

This is a browser prototype. It does not monitor or block actual mobile apps.
The countdowns use real time, so full-duration tests require waiting.
